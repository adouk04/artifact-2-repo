Choose two teams and press Play one game. The first run downloads the Python engine (about 10 MB), so give it a few seconds.

Starters come from public depth charts and team ratings from NFL.com’s 2026 stats, both captured October 18, 2026. Player ratings are unofficial estimates. This is a simulation for fun and does not predict real games.

The game engine is the same Python program that runs on the command line (footballsim.py), running in your browser.
